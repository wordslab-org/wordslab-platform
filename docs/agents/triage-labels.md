# Triage labels

Five canonical triage roles, each label string equal to its name:

| Label | Role |
|---|---|
| `needs-triage` | Issue or PR waiting to be triaged |
| `needs-info` | Waiting on information from the reporter |
| `ready-for-agent` | Triaged, actionable by an AI agent |
| `ready-for-human` | Triaged, needs a human |
| `wontfix` | Deliberately not fixing |
