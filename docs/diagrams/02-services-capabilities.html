Wordslab Platform — Services & Capabilities

11 v1 services + the combined Publishing & Governance service. A capability is an in-process module inside a service (own logic, routes, UI — shared contract, DB, auth). A capability may graduate to its own service (ADR-0002, map ticket #18).

Missing from the map (deliberate): the platform core (see diagram 01) and the dashboard (the core's UI, not a service). Every service also exposes the uniform contract: human UI + agent MCP + deterministic OpenAPI (ADR-0001).
