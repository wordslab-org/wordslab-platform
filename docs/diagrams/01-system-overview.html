Wordslab Platform — System Overview

Home-scale, 100% OSS AI platform — leader/worker fleet, services + control-only core, one front door (ADR-0003/0004/0014)

The three commitments

  • • Openness — 100% OSS, honestly visible
  • • Simplicity — the main feature; home scale
  • • Control — own data, choose impls, no black box

Control vs request path

  • • Core centralizes control only
  • • Services own their DBs, logic, UI, API
  • • Routing = placement outcome, visible per call

Trust model

  • • Join by type-in code → machine identity key
  • • Per-service Bearer keys
  • • No public ports; overlay (WireGuard) for internet crossings
